# Cámara y Senado

Ruta: /politico y /politico/[slug]. Menú: Cámara. Permitir elegir Diputados o Senado y buscar por nombre, partido, distrito o región. Mantener enlaces compartibles con cargo y q; no filtrar en el servidor por parámetros de una petición en un export estático.

El directorio consume nómina, partidos y datos publicados de ficha. Preservar fuente, importe y período de cada componente. No consultar D1 para rankings de apoyo dentro del directorio; Rankings es un área aplazada.

La siguiente entrega de ficha tiene resumen inicial, menú izquierdo y un panel visible a la vez; selector equivalente en móvil. Gastos, apoyo, dietas y votaciones se estabilizan en sus módulos antes de integrarse al dashboard general.

Pruebas: filtros combinados, tildes, URL inicial, cambio de cámara conservando búsqueda, resultados vacíos, paginación tras filtrar y navegación hacia la ficha. Comparar Bianchi y Kaiser contra el release productivo. Consultar docs/modules/navegacion y docs/modules/fichas.
