# Cómo contribuir

## Reportar bugs de datos

Si encuentras un dato incorrecto o desactualizado:

1. Abre un issue con el template "Bug de datos"
2. Incluye:
   - URL de la página afectada
   - Dato incorrecto que ves
   - Dato correcto según fuente oficial
   - Link a la fuente oficial (BCN, Senado, etc.)

Verificamos contra la fuente oficial y corregimos en el siguiente corte.

## Pull requests

Aceptamos PRs para:
- Nuevas fuentes oficiales (con justificación)
- Mejoras de performance de ETLs
- Fixes de bugs de código

NO aceptamos PRs para:
- Cambios de metodología sin evidencia
- Datos sintéticos o no verificables
- Contenido editorial (eso va en el repo privado)
